Repository Stack What it does
hoocode TypeScript Deterministic terminal coding agent, published to npm. Permission gate on every edit and command; four scoped modes; MCP servers and subagents. Four packages including a unified LLM API across 25+ providers.
embeddingsearchtools Rust Embedding search engine. MiniLM via ONNX Runtime with int8 weights bundled into the binary; exact and HNSW approximate indexes; BM25 lexical fusion for hybrid retrieval; mmap-friendly store, CLI and long-lived daemon.
voicetools Rust Offline speech-to-text for the terminal. Microphone capture through voice-activity detection into Parakeet-TDT on ONNX Runtime, 25 languages, with a Whisper fallback.
webtools Rust Token-efficient fetch and search for LLM agents. Reference-style URL preservation turns links into single-token markers; output is capped to a token budget.
